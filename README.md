# 🧭 RouteMatrix – AI Travel Itinerary Planner

An AI-powered travel planning application that generates personalized multi-day travel itineraries based on destination, trip duration, budget, interests, and accommodation preferences. Powered by Google's Gemini API, RouteMatrix delivers intelligent, location-aware travel recommendations through a clean and interactive Streamlit interface.
---

## ✨ Features

### Core Functionality
- **AI-Powered Itinerary Generation** - Generate personalized multi-day travel plans using Gemini API.
- **Smart Travel Recommendations** - Receive destination-specific attractions, activities, food suggestions, and travel tips.
- **Personalized Planning** - Customize itineraries based on destination, budget, duration, interests, accommodation type, and additional preferences.
- **Interactive User Interface** - Clean and responsive Streamlit-based interface for seamless trip planning.
- **Dynamic AI Responses** - Generate unique itineraries tailored to every travel request.

### AI Capabilities
- 🤖 Dynamic itinerary generation using **Google Gemini API**
- 📍 Location-specific travel recommendations
- 🗓️ Day-wise travel planning
- 💰 Budget-aware itinerary optimization
- 🎯 Personalized suggestions based on user interests

### Technical Features
- ✅ Responsive Streamlit interface
- ✅ Dynamic AI-generated recommendations
- ✅ Modular and maintainable Python architecture
- ✅ Fast itinerary generation
- ✅ User-friendly travel planning workflow

## 🚀 Quick Start

### Installation

```bash
# Clone the repository
git clone https://github.com/<your-username>/RouteMatrix.git

# Navigate to the project
cd RouteMatrix

# Install dependencies
pip install -r requirements.txt

# Run the application
streamlit run app.py
```

The application will be available at:

```
http://localhost:8501
```


## 🤖 AI Workflow

1. Enter:
   - Destination
   - Trip duration
   - Budget
   - Interests
   - Preferred accommodation
   - Additional requirements
2. RouteMatrix sends the request to the **Google Gemini API**.
3. AI generates a personalized day-wise travel itinerary.
4. Users receive destination-specific recommendations for attractions, food, activities, and travel tips.
