# RouteMatrix-AI-Travel-Itinerary-Planner

- Built an AI-powered web application that generates personalized travel itineraries based on destination, budget, duration, and preferences.
- Integrated Gemini API to generate dynamic multi-day travel plans with location-specific recommendations.
- Designed a secure authentication and itinerary management system that delivers personalized AI-generated travel recommendations while ensuring seamless user experience and data persistence.
